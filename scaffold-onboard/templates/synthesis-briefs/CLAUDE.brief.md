## Synthesis guidance

This file synthesizes the project's CLAUDE.md — the tiered-context router that tells
an LLM which memory-bank files to load for different conversation types. It is loaded
on every session. Keep it compact, navigational, and grounded in the spec.

Tier 0 — always preloaded: emit this section with the canonical preload list VERBATIM:
  - `.claude/memory-bank/index.md`
  - `.claude/memory-bank/00-project-brief.md`
  - `.claude/memory-bank/05-active-context.md`
  - `MASTER-SPEC.md` §Executive Summary + §Phase 1 only
Do NOT alter this list. The Tier 0 contract is fixed across all projects.

Project in 5 lines: synthesize a 5-line project summary using MASTER-SPEC fields:

    store from `phase_5.2.2`
Do NOT deviate from the 5-line format or add a sixth line. Distil, do not truncate.
