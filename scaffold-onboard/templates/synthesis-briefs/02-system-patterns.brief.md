## Synthesis guidance

This file is the branch-loaded architecture context document. It is loaded when a
conversation touches architecture, system design, or security. Keep it precise and
decision-grounded — no aspirational content.

Architecture shape: synthesize the overall architecture pattern from `phase_5.1.1`
(e.g., monolith, layered monolith, service-oriented, event-driven, CLI pipeline).
Name the primary modules or services and their responsibilities. Ground in the
project's actual language and stack, not generic architectural tropes.

Async / event-driven boundaries: describe any async or event-driven boundaries from
`phase_5.1.2`. If the project has no async boundaries, state "Synchronous only" rather
than leaving this empty. Name specific message queues, event buses, or background-job
systems if recorded in the spec.

Security posture: synthesize all five security sub-fields as a compact structured
list (matching the template's field layout):
  - Sensitive data: derive from `phase_4.1.1` — what data is sensitive and how it
    must be protected (encryption, masking, retention).
  - Regulated domain: derive from `phase_4.1.2` — compliance regime (GDPR, HIPAA,
    SOC 2, none).
  - Auth model: derive from `phase_4.2.1` — authentication and authorisation approach.
  - Tenancy: derive from `phase_4.2.2` — single-tenant / multi-tenant / isolated.
  - External attack surface: derive from `phase_4.3.1` — inbound interfaces exposed
    (HTTP, gRPC, webhook, CLI, none).

Performance & scale targets: synthesize the two scale sub-fields:
  - Expected scale (6 months): from `phase_5.3.1` — volume, user count, request rate.
  - Latency targets (hot paths): from `phase_5.3.2` — specific latency or throughput
    budgets for the most performance-critical operations.
Express targets as test-able constraints (e.g., "p95 < 200 ms", "10k req/s sustained").

ADR index: emit the canonical pointer sentence exactly as it appears in the template
("See `docs/adr/` for recorded decisions (generated by `/scaffold-docs`)."). Do NOT
populate this with specific ADR titles — that is done by the ADR-0001 synthesis agent.

See also: emit the canonical cross-reference links exactly as they appear in the
template (MASTER-SPEC §Phase 4 and §Phase 5).
